## 🎮 What Is This?

**AI Dungeon Master** is a tabletop RPG experience that runs entirely in your browser. You create characters, choose a campaign setting, and an AI Game Master narrates the story, reacts to your decisions, and drives the adventure forward — all in real time.

No installation. No backend. Just your browser and a free Gemini API key.

---

## ✨ Features

### 🧙 Character Creation Wizard
- **7 Races** — Human, Elf, Dwarf, Halfling, Orc, Tiefling, Dragonborn
- **8 Classes** — Fighter, Rogue, Wizard, Cleric, Barbarian, Bard, Paladin, Ranger
- **8 Backgrounds** — Soldier, Scholar, Criminal, Traveler, Noble, Merchant, Acolyte, Folk Hero
- **3 Stat Methods** — Dice Roll (4d6 drop lowest), Standard Array, Point Buy
- **Alignment System** — Full 3×3 grid (Lawful Good → Chaotic Evil)
- **🎲 Random Character** — One click to generate a fully randomized character and jump straight to the summary

### 🗺️ AI-Driven Gameplay
- Dynamic narrative generated by **Gemini 2.5 Flash** in Turkish
- Every action goes through a **D20 dice roll** with DC checks
- 2–4 contextual action choices per scene (or type your own)
- Primary stat recommendations highlighted during character creation
- Background & alignment sent to AI for richer roleplay

### ⚔️ D&D 5e Inspired Mechanics
- STR / DEX / CON / INT / WIS / CHA stat system
- Proficiency bonuses, modifiers, HP and AC calculations
- Animated D20 roll with critical hit (⭐) and fumble (💀) effects
- Race bonuses applied automatically to base stats

### 🎨 UI / UX
- Dark fantasy aesthetic — Cinzel font, parchment color palette
- Scrollable chat feed — DM on the left, players on the right
- Scene images via [Pollinations.ai](https://pollinations.ai) (free, no key needed)
- Character portraits generated per race/class combination
- Atmosphere badges: ⚔️ Combat · 🗺️ Exploration · 💬 Social · 🧩 Puzzle

### 💾 Session Management
- Auto-save to `localStorage` — resume where you left off
- In-game API key update without losing progress
- Up to 6 players in a single session

### 🔁 Reliability
- 5-stage JSON fallback parser for Gemini responses
- Auto-retry on 503 / 429 with exponential backoff (4s → 8s → 16s)
- 45-second safety timer prevents infinite loading states

## 🚀 Getting Started

### Prerequisites
- A free **Google Gemini API key** from [aistudio.google.com](https://aistudio.google.com) — no credit card required.

### Run Locally

```bash
# Clone the repo
git clone https://github.com/emrekoyuncuu/frp-game.git
cd frp-game

# Serve with any static file server
npx serve -l 3000 .
# or
python3 -m http.server 3000
```

Then open `http://localhost:3000` in your browser.

> **Note:** Opening `index.html` directly via `file://` also works — no build step, no dependencies.

## 🎯 How to Play

1. **Enter your Gemini API key** (stored locally in your browser, never sent anywhere else)
2. **Set up the lobby** — choose 1–6 players and enter their names
3. **Create characters** — race, class, background, stats, alignment (or hit 🎲 for random)
4. **Describe your campaign** — write a premise or pick from the examples
5. **Play!** — the AI narrates, you choose actions and roll the dice

## 🔑 Privacy

Your API key is stored **only in your browser's `localStorage`**. It is never sent to any server other than Google's Gemini API directly from your browser.
